Nuestra Sección C y el Bachillerato en Software

Somos la Sección C del Bachillerato en Software del Instituto Nacional de Santiago de María.

En nuestra sección aprendemos trabajando en equipo, compartiendo ideas y apoyándonos en cada actividad.

El bachillerato en software nos enseña a crear programas, páginas web y aplicaciones desde cero.

Practicamos herramientas como HTML, CSS y JavaScript, las mismas que usamos para construir esta tienda.

Esta página es una muestra de lo que hemos aprendido y de nuestro deseo de ser futuros profesionales de la tecnología.

Mi Reflexión

Hacer esta página web me ayudó a entender que programar es más que escribir código: es resolver problemas paso a paso.

Al principio me costó organizar las imágenes, los videos y los estilos, pero con práctica y paciencia fui mejorando.

Aprendí a usar HTML para la estructura, CSS para el diseño y JavaScript para que la tienda tuviera una ventana de pago que funciona.

También comprendí que los errores son parte del aprendizaje, porque cada uno me enseñó algo nuevo.

Me siento motivado a seguir aprendiendo y a crear proyectos cada vez mejores en mi bachillerato en software.

— Alfredo Emmanuel Garay Cruz, Sección C
